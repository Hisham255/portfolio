# Personal Portfolio
 
A single-page, fully responsive personal portfolio website showcasing my projects, skills, and contact information.
 
## 🔗 Live Demo
https://hisham255.github.io/portfolio/
 
## 🛠️ Built With
- **HTML5** – page structure
- **Tailwind CSS** – utility-first styling and responsive layout
- **JavaScript** – interactivity
- **AOS (Animate On Scroll)** – scroll-triggered animations
- **Font Awesome** – icons
## ✨ Features
- Fully responsive design (desktop, tablet, and mobile)
- Smooth scroll animations powered by AOS
- Clean, modern UI built with Tailwind CSS
- Showcases personal projects and skills in one page

## 🚀 Getting Started
1. Clone the repository
```bash
   git clone https://github.com/Hisham255/portfolio.git
```
2. Open `index.html` in your browser, or serve it with a local server (e.g. Live Server extension in VS Code).
